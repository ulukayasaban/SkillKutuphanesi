# OpenAPI spec cache

This folder is intended to hold a cached copy of Etsy’s OpenAPI spec JSON.

Run:

```
python ../../scripts/fetch_openapi_spec.py
```

to download the current spec into this folder (filename: `etsy-openapi-3.0.0.json`).

Source:
- https://www.etsy.com/openapi/generated/oas/3.0.0.json
