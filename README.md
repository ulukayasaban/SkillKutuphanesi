# Skill kütüphanesi: süreç planlama paketi

Gemini'ye verilecek bağlam. Sırayla oku:
1. `notlar/istenen-surec.md` — istenen süreç (amaç, 10 görev, kurallar, onay merdiveni, senaryolar).
2. `notlar/istenen-ve-mevcut-karsilastirma.md` — istenen ile bugünkü yapının karşılaştırması (hazır / yarım / yok).
3. `notlar/yeni-surec-plani-calisma.md` — ortak plan, kararlar, ölçümler.
4. `notlar/plan-tur-surecleri.md` ve `surecler/` — bir hafta önce kurulan tür bazlı giriş süreçleri (temel alınacak yapı).

Görev: bu süreci bugünkü yapının üstüne, adım adım ve her adımda tek karar sorarak planla. Hiçbir şeyi kurma ya da silme; yalnız plan üret. Sade Türkçe, kısa.
